# CozyBirds

CozyBirds is a lightweight ambient wildlife mod for Fabric that adds realistic birds to your Minecraft worlds.
It features city pigeons and European magpies with lifelike animations, natural perching on roofs and trees, and beautiful flock murmurations.
The mod is designed to run smoothly on servers and modpacks without causing lag.
All feather drops are fully compatible with vanilla crafting recipes.
